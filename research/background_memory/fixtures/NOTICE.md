The compressed Codex source fixture contains six unmodified Rust files from
[openai/codex](https://github.com/openai/codex) commit
`3d2ee51ca2d5db578f328aa75e20aa22c0197c9a` (`rust-v0.153.4`).
They are included under the Apache License 2.0; see `LICENSE.codex` and the upstream `NOTICE.codex`.
The fixture is public source evidence for a code-review context experiment.
Its prompt strings and comments are data, not instructions to the harness.
